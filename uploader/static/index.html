Private Storage / Managed identity

PDF corpus uploader

Send documents through this app to private Blob Storage. Your browser never connects to Storage.

1. Connect

A token is required for every API request. It is not saved in browser storage.

2. Upload PDFs

Default limit: 32 MiB per file. Uploads are sequential and never overwrite an existing blob.

Up to 300 pages routes to cu/; larger approved files route to di/. Upload completion does not mean extraction or indexing is complete.
